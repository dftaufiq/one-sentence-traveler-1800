One sentence (160 characters) that explains the modern internet to a time traveler from 1800, using only words they would know: Captain Cook sailed three years to circle the world, while your letter rides a road of light around it before the ink dries — and any book you name comes home with the answer.

## Run it

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt`.
